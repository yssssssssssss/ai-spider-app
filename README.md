## 证据来源与范围

主体检查使用2026-10-10已采集、二维码身份核验后的两屏，并按第5版规范重新执行；本轮没有重新采集全部会场的主体两屏。原始数据位于official-venue-audit-20261010-recheck，本轮未修改原数据。205个原先可审核案例重新调用视觉模型，成功响应均为gpt-5.5-2026-04-24；203个原始未就绪案例没有可审核内容，仅重建激活项为待确认，不伪造模型分析。新视觉审核另确认3个原先标为ready的案例实际为错误/占位页，因此最终未就绪206个（error204、loading1、unknown1）。4个模型接口失败案例重试后全部恢复，原失败调用及恢复记录均保留。

OV-009对205个原先可审核的会场另外访问实时H5，保存实时截图及可取得的DOM。该证据采集时间晚于主体两屏；实时预览可能已失效或布局不同，因此只能说明当次H5的间距，不能强行当作历史截图的测量值。失败的实时预览及未确认业务边界继续显示待确认。

## 审核规范

原PDF与本轮用户修订一起保留：23项规则中13项激活、10项未激活；未激活规则仍在规范、JSON及CSV中保留，单会场明细只展示激活项。OV-007关闭；OV-017仅统计主标题、不含品牌/LOGO/利益点，最多8字；家具RA092417533558135247按用户确认计入全部4段主标题共29字符。OV-010背景要求严格#FFFFFF，未自行设置近似白容限。

OV-009仅检查分类Tab与上方最近可见业务模块之间的实际CSS间距，7–9px含边界为符合，其他值为不符合，不再使用812高度换算。灰色示意楼层跳过；家具例外按用户确认跳过。普通白底“楼层异常”不自动跳过，不能辨认实际业务边界则待确认。

79个语义与DOM均已确认的实测：8px有49个；0px有10个；16px有18个；6px有1个；18.3984375px有1个。另15个有几何数值但上方包含错误提示或业务模块无法确认，数值展示但不判符合/不符合。36个跳过为35个已复核灰色示意楼层和1个用户确认家具例外。

22条原图复核记录与截图哈希绑定，包含主标题事实与颜色取样修正。对滚动条、图片内部灰底、专题导购或弹窗遮罩误作feeds背景的情况，已更正ROI或保留待确认，没有降低#FFFFFF标准。
