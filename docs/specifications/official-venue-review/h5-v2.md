# 官方会场H5审核：用户口径第2版

本轮配置为 [h5-v2.json](h5-v2.json)，依据2026-10-11用户补充的要求。PDF提取版 [walkthrough.json](walkthrough.json) 保持原样；新版每项的 `original` 保存原始规则，`rule_origin` 区分PDF要求与用户修订，不把用户新增要求归因于PDF。

每项有 `enabled` 激活状态。未激活仍保留原规则，结果为 `disabled`，不计入通过、失败、待确认或适用性覆盖率；要恢复规则，修改配置后使用新的输出目录重新审核。冻结报告不会跟随配置文件变化。

共14项激活、9项未激活。OV-015仍为建议，偏离不计入强制问题。

用户已确认OV-017只统计主标题，不含品牌、LOGO、活动标识和利益点。每个汉字、字母、数字、标点计1，空白不计；先保存精确识别文本，再由程序计数，不采用模型直接给出的字数。主标题区域不完整、不可读或超出头图时，保留待确认。

用户已确认以812px整屏高度作为本轮间距换算基准。原图390×844，目标间距为 `24 × 844 / 812 = 24.9458` 截图像素；测得25截图像素时，换算为 `25 × 812 / 844 = 24.0521` 基准像素。此换算针对整屏高度，不扣导航或浏览器栏高度。尚无验收误差容限；模型定位边缘与纯色条带也不能自动证明精确组件边界，因此只记录数值及差值，不强行判通过/失败。

## 20个案例的执行方式

使用 [固定案例清单](../../examples/official-venue-pilot20.json)，覆盖白/非白背景、人物、可选组件、首屏商品、异常和加载状态。该清单是功能覆盖样本，不用于推断全量问题比例。

```bash
python scripts/rerun_venue_audit.py \
  --source data/tasks/official-venue-audit-20261010-recheck \
  --output data/tasks/official-venue-audit-20261011-h5-v2-pilot20 \
  --spec docs/specifications/official-venue-review/h5-v2.json \
  --records-file docs/examples/official-venue-pilot20.json \
  --concurrency 4
python scripts/build_venue_recheck_report.py \
  --output data/tasks/official-venue-audit-20261011-h5-v2-pilot20
python scripts/validate_venue_reaudit.py \
  --output data/tasks/official-venue-audit-20261011-h5-v2-pilot20
```

输出只包含这20个会场和40张冻结原图，保留会场名称/ID/通天塔项目ID、全部23项记录、规则激活状态、结构化事实、模型调用、像素数值及原图哈希。没有重新采集线上页面。原408会场报告不覆盖。

模型只收到激活规则。商品/人物计数需要完整头图和逐个对象证据；倒计时位置由同一头图主标题和倒计时边界比较；首屏商品必须来自滚动前的首屏。预览异常或示意楼层影响高度/顺序时，相应检查保留待确认。

首轮20案例结果见 [审核报告](../../../data/tasks/official-venue-audit-20261011-h5-v2-pilot20/report.html) 和 [结论说明](../../../data/tasks/official-venue-audit-20261011-h5-v2-pilot20/README.md)。用户已确认允许表格名称与截图内容名称不同：保留表格名称/ID映射，按实际截图审核并注明差异。

针对部分文字范围、对象类别和背景区域的原图复核保存在输出目录的 `review-overrides.json`，绑定两屏截图哈希；原始模型响应不改写。规则结论仍由修正后的事实计算，不直接覆盖为通过/失败。用户已解决的提示可以按完整原文解除，并保留在原始响应和旧报告中。
