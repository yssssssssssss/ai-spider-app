# 官方会场H5审核：用户口径第4版

本版仅修订 OV-009，其余规则沿用 [第3版](h5-v3.md)。[配置文件](h5-v4.json) 保留全部23项，13项激活、10项未激活。

OV-009 保持激活，按会场判断适用性：存在灰色示意楼层时跳过；用户进一步确认，家具会场的楼层异常提示也跳过，此项确认仅记录为该家具会场的跳过例外。跳过记录为 `not_applicable`，不是通过，也不是删除规则。

对适用会场，仅测分类Tab容器顶部与紧邻上方可见业务模块底部之间的垂直距离。不测Tab下方feeds交界，也不测其他楼层交界。跳过脚本、零高度隐藏模块；间隔组件仍计入距离。Tab自己的内部留白不计入模块之间的间距。

本轮采用 Ego Lite 在390×844 CSS视口、页面DPR=2、视口缩放1（导出截图同为390×844，因此尺寸比例为1:1）的H5页面读取 `getBoundingClientRect`，同时保存实时截图并与历史截图检查对应位置。H5布局数值与历史截图分别保存，不能把实时DOM值说成历史截图直接推算值。

24PX继续按已确认的812整屏高度基准换算，当前目标为24×844÷812≈24.9458截图像素。尚无验收容限，因此报告实际数值和差值，不直接判数值通过或失败。

本轮复核仍为原来的10个会场：婚庆用品、超级品牌联盟、家具跳过；京东电器、美酒、元器件、汽车装饰小件、纪念币邮币、产业投资、鞋靴测量分类Tab上方间距。其他22项沿用上一轮冻结截图结论，本轮不重新调用模型。
